Key highlights

    Reading these numbers

    Radar never returns absolute request counts — it normalizes every response with MIN0_MAX, which divides each value by the largest value in that response. Ratios within one file are therefore real (0.80 is twice 0.40), but a value only means something next to the other values in the same file. Every day charted here came back in a single API call, so all six months share one maximum and can be compared to each other. Figures from a different run, or from the separate monthly archive files, sit on a different scale. See Radar's normalization notes.
